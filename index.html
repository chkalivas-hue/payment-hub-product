RECONCILIATION

One payment. Multiple sources of truth.

Reconciliation verifies that the Hub, Core Banking, network and settlement information agree.

PAY-000001

Hub Payment ↔ Core Posting ↔ Network Transaction ↔ Nostro / Statement

Matched

All required records agree.

Partially Matched

Expected records are pending or missing.

Exception

Mismatch, missing posting, amount difference or missing settlement.
