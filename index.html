DOMAIN MODEL
Canonical Payment Model

  
Common internal representation
Everything entering the Hub is transformed into a payment-centric internal model. The model carries transaction facts; routing enriches it with processing decisions and network-specific references.

PROCESSING LAYER
Engines & responsibilities

  
Orchestration Engine
Coordinates the workflow and decides what happens next.
Validation Engine
Runs structural, business and configuration validations.
Routing Engine
Selects rail, scheme, correspondent, Nostro and processing profile.
ISO 20022 Engine
Maps Canonical + Routing Decision into the required ISO message.
Network Adapter
Handles connectivity to the selected payment infrastructure.
Reconciliation Engine
Matches Hub, Core, network and settlement records.
